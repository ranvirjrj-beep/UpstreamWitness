# Security policy

Please do not place exploit details, credentials, private reports, or customer data in a public issue.

For a vulnerability in UpstreamWitness itself, prefer GitHub private vulnerability reporting / **Report a vulnerability** on the repository when available. If that channel is unavailable, open a minimal public issue that contains no exploit details and asks the maintainer to establish a private contact channel.

UpstreamWitness is an evidence-correlation tool, not an exploit scanner. Reports generated by UpstreamWitness should be manually verified before they are used in security, payment, or dispute communications.
